## Laba2 — Валидатор СНИЛС

Утилита для проверки корректности номеров СНИЛС (Страховой Номер Индивидуального Лицевого Счета) с несколькими режимами работы.

### Возможности

- Ручной ввод и проверка одного СНИЛС
- Извлечение и валидация всех СНИЛС из веб-страницы по URL
- Поиск и проверка СНИЛС в текстовом файле
- Автоматическое форматирование найденных номеров
- Проверка контрольной суммы по официальному алгоритму

### Алгоритм валидации

СНИЛС считается корректным, если:
1. Формат соответствует `XXX-XXX-XXX YY` (11 цифр)
2. Контрольная сумма совпадает с расчётной

Расчёт контрольной суммы:
- Первые 9 цифр умножаются на веса от 9 до 1
- Сумма произведений модулируется по правилам ПФР
- Результат сравнивается с последними двумя цифрами

### Структура проекта

```
Laba2/
├── main.py                    # CLI-интерфейс с меню выбора режима
├── validate_snils.py          # Модуль валидации и извлечения СНИЛС
├── test_validate_snils.py     # Тесты для проверки функционала
├── sample_snils.txt           # Примеры СНИЛС для тестирования
└── invalid_file.txt           # Тестовый файл с ошибками
```

### Использование

**Интерактивный режим:**

```bash
python main.py
```

Программа предложит выбрать один из режимов работы.

**Программный вызов:**

```python
from validate_snils import validate_snils, validate_snils_from_file, validate_snils_from_url

# Проверка одного номера
is_valid = validate_snils("123-456-789 00")

# Поиск в файле
valid_list = validate_snils_from_file("sample_snils.txt")

# Извлечение с веб-страницы
valid_list = validate_snils_from_url("https://example.com/page")
```

### Запуск тестов

```bash
python test_validate_snils.py
```

Тесты покрывают:
- Корректные СНИЛС разных форматов
- Невалидные номера (неверная контрольная сумма)
- Чтение из файлов

### Форматы ввода

Программа распознаёт СНИЛС в разных форматах и нормализует их:
- `123-456-789 00`
- `123 456 789 00`
- `12345678900`

Все варианты приводятся к стандартному виду `XXX-XXX-XXX YY`.
